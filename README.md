# Sprint_4

Автоматизированные UI-тесты учебного сервиса «Яндекс Самокат».

## Технологии

- Java 11
- Maven
- JUnit 4
- Selenium WebDriver
- Page Object

## Реализованные проверки

- проверка ответов в разделе «Вопросы о важном»;
- оформление заказа через верхнюю кнопку «Заказать»;
- оформление заказа через нижнюю кнопку «Заказать»;
- параметризованные тестовые данные;
- запуск тестов в Google Chrome.

## Запуск тестов
```bash
mvn clean test
